📊 Project Title

PHOTON – Real-Time Stock Price Streaming System

🧠 Project Overview

PHOTON is a real-time stock ticker system designed to stream live stock price updates from the backend to the frontend with minimal delay. The project demonstrates how modern web systems handle real-time data using APIs and continuous updates instead of traditional refresh-based systems.

The system simulates live stock price changes and delivers them instantly to users, similar to how trading platforms and financial dashboards operate in the real world.

🎯 Objectives

Build a real-time data streaming backend

Deliver live stock price updates to the frontend

Understand event-driven and real-time systems

Learn FastAPI-based backend development

Create a scalable foundation for financial dashboards


🧩 Key Components

Backend: FastAPI (Python)

Frontend: HTML + JavaScript

Communication: Real-time API updates

Architecture: Client–Server Model


🌟 Why This Project Is Different

Focuses on real-time streaming, not static data

Mimics real-world trading dashboards

Uses modern backend frameworks

Lightweight, fast, and scalable design

Practical exposure to live systems used in fintech platforms
